# Project skills

These skills adapt the pineapple spec/ADR loop for Open Brain. Pi (and other
agents that read `.agents/skills/`) load them automatically.

| Skill | When to use |
| ----- | ----------- |
| [adr-author](adr-author/SKILL.md) | Write, capture, or supersede an ADR |
| [adr-review](adr-review/SKILL.md) | Review an ADR without editing it |
| [spec-author](spec-author/SKILL.md) | Draft or revise a feature spec |
| [test-author](test-author/SKILL.md) | Blind test plan, spec gaps, issue comment |
| [spec-implement](spec-implement/SKILL.md) | Implement one spec slice from spec + issue plan |
| [test-review](test-review/SKILL.md) | Did the tests pin the spec and the issue plan? |
| [validation-gate](validation-gate/SKILL.md) | Rebase, review, risk-score, open the PR |
| [pr](pr/SKILL.md) | Open a PR with the template filled in |
| [pr-review](pr-review/SKILL.md) | Adversarial review of a branch or PR |
| [pr-respond](pr-respond/SKILL.md) | Address review comments and red CI |

House rules live in the docs, not here:

- Specs: [`docs/specs/SPECS.md`](../../docs/specs/SPECS.md)
- ADRs: [`docs/decisions/README.md`](../../docs/decisions/README.md)
- Method: [`docs/README.md`](../../docs/README.md)
