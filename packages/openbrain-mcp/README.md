# @snaveevans/openbrain-mcp

MCP server for interacting with Open Brain memories.

## Run

```bash
npx -y @snaveevans/openbrain-mcp --base-url https://your-openbrain-host --api-key your-api-key
```

## Environment variables

- `OPENBRAIN_API_KEY`
- `OPENBRAIN_BASE_URL`

## Tools

- `create_memory`
- `delete_memory`
- `search_memories`
